# Mustafa Yorulmaz — Personal Website

A responsive, dark premium personal website focused on chess lessons. Built with plain HTML, CSS, and JavaScript; no build step or dependencies required.

## Before publishing
1. Open `index.html`.
2. Find `YOUR-EMAIL@example.com` and replace it with your real email address in both the `href` and the visible note (or rewrite the note).
3. Review the copy and adjust any lesson descriptions to match what you actually offer.

## Publish with GitHub Pages
1. Create a GitHub repository. For a personal account site, name it exactly `YOUR-GITHUB-USERNAME.github.io`. For a project site, any repository name works.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes, then open the URL shown in the Pages settings.

For a personal account site, the URL is `https://YOUR-GITHUB-USERNAME.github.io/`. For a project site, it is typically `https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/`.

Note: GitHub Pages publishes your site publicly. Do not add private information to the repository or website.
